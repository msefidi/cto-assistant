# Eviplex: product management routines

How Mahyar runs Eviplex as PM. Linear holds the current projects and issues; this file holds the rules.

## Linear (team EVP), set up 30 Oct 2026

- **Track** (required, one per issue; projects carry the same values as a project label): Core product · Answer quality · Growth · Admin & analytics · Tech health · Product research and UX. ("Product" was taken by a workspace label, hence "Core product".)
- **Surface** (optional): Web app · Mobile app · Admin · Mixpanel · Website · App Store, each with a title prefix (`Web:`, `Mobile:`, `Admin:`, `Mixpanel:`, `Website:`, `App Store:`). Only when the issue is bound to one surface; cross-surface work gets none and is split into sub-issues later. Never use the track as a prefix.
- **Naming:** issues are verbs, projects are nouns (an outcome or topic), sentence case, "and" not "&". Bug fixes stay without a project.
- **Views:** roadmap https://linear.app/fomf/projects/view/eviplex-b5e71e7aedfe; Watchlist (small but important items, label "Watchlist") https://linear.app/fomf/view/watchlist-fadb0b618a63; changelog (done issues) https://linear.app/fomf/view/eviplex-changelog-a73f93b736b3. The Linear connector cannot create saved views; Mahyar builds them by hand.
- **Cycles** last 2 weeks and start on Thursday.
- Linear is the place for product work (bugs, improvements, feature requests), not "engineering work".

**Why:** Wafa kept opening a Word document in meetings because Linear had no top layer (projects) and no way to follow small items.

## Meetings and outputs

- **Eviplex weekly**, Friday mornings, run by Mahyar: roadmap review of projects, then the Watchlist.
- **Weekly plan memo** in the meeting's Teams chat, grouped by project: `../weekly/AGENTS.md`.
- **Internal changelog email** (German, company-wide): `../changelog/AGENTS.md`.
