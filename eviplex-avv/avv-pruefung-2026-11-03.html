Anlage 2.1: Was davon heute stimmt

Stimmt

  • Hosting in Frankfurt (europe-west3)
  • Schlüssel im Secret Manager, nicht im Code
  • API-Schlüssel laufzeitkonstant geprüft
  • Backups täglich, 7 Tage, plus Point-in-Time
  • Braintrust auf EU-Servern, Namen maskiert

Stimmt nicht: Datenfluss

  • „Nur EU, fail closed“: OpenAI ohne EU-Region; Abweichung wird nur geloggt
  • Diktat geht an den US-Endpunkt von OpenAI
  • „Keine Kopien“: DB-Dump (11,5 GB, Nov. 2025) und Prod-Klon (Sep. 2026) liegen noch

Stimmt nicht: Betrieb

  • „Nicht öffentlich erreichbar“: Datenbank hat öffentliche IP, Retool freigeschaltet
  • „Alles mit TLS“: Datenbank erlaubt Unverschlüsseltes, Redis ohne TLS
  • „Vier-Augen-Prüfung Pflicht“: Pull Request nötig, aber 0 Freigaben
  • „Ratenbegrenzung“: nur Monatskontingente
