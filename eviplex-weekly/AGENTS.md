# Eviplex weekly plan memo

Recurring. Mahyar posts a plan for the Eviplex team in the Eviplex weekly Teams meeting chat, in English. One file per week in this folder, named by the Monday (`YYYY-MM-DD.md`). Since 13 Nov 2026 the plan is grouped by project; Mahyar edited the first one himself (`2026-11-16.md`), and that version is the template. Monthly plans use the same format.

## Format

- Title: "Plan for the coming week (dd.mm to dd.mm)"
- Numbered projects in roadmap order, bold name and the main owner in brackets (only the main owner, no secondary names)
- Under each project: "This week:" with 1–2 outcome bullets, then "Target: dd.mm" (the project's target date, "tbd" when unknown)
- "Side issues": one bullet per owner, topics comma-separated, owner in brackets
- "On the horizon": things we might build, research and early meetings (e.g. MDR, KIS)
- No separate line for Mahyar; his items go under the project or under "On the horizon"

## How to draft one

1. Start from the previous week's file.
2. Take projects, owners and target dates from the EVP Linear projects (roadmap view, see `../eviplex/pm.md`) and the current cycle.
3. Keep it short. Security findings never go into the chat; flag them to Mahyar separately.
4. Save it here as the next Monday's file.

**Why this format:** a per-person list scattered shared work and did not say what "done" looks like; the project order matches the roadmap review in the Friday weekly.
