- Lead every analysis reply with the finding and the numbers in a small table, then one caveat. He reuses these directly in slides.
- He builds pages step by step ("simplify", "take this part out", "add a section for X"): do exactly that, one topic per step, nothing extra.
- When he pastes a definition table or a mock of the shape he wants, implement it literally and state the few gap-filling choices you made.
- Ask before changing an agreed definition or adding a data source outside `fomf-dl`.

**Why:** how he worked on the B2C Value Journey and the other B2C pages (Sep–Oct 2026).

**How to apply:** for any analysis or dashboard for him. Agreed B2C definitions: `cto-assistant/platform/knowledge/b2c-members.md`. See [[comms-style-short]].
