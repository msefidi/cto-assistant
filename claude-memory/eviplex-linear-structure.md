On 30 Oct 2026 the EVP Linear team got two team-level single-select label groups:
- **Track** (required, one per issue): Core product · Answer quality · Growth · Admin & analytics · Tech health. ("Product" was taken by a workspace label, hence "Core product".)
- **Surface** (optional): Web app · Mobile app · Admin · Mixpanel · Website · App Store. Each matches a title prefix (`Web:`, `Mobile:`, `Admin:`, `Mixpanel:`, `Website:`, `App Store:`).

Rule from Mahyar: use Surface/prefix **only** when the issue is bound to one surface; cross-surface work gets none and is split into sub-issues later. Never use the track as a prefix.

64 active issues (Todo/In Progress/In Review + EVP-721, EVP-1172) were labelled; backlog not yet done.
